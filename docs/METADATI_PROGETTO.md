## Scopo

NosAi è un runtime di intelligenza artificiale orientato all'automazione controllata di NosTale. Il sistema è progettato come ciclo chiuso di osservazione, modellazione dello stato, simulazione, pianificazione, autorizzazione, esecuzione, verifica e recupero.
