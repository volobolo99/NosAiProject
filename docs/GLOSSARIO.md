# NosAi — Glossario

| Termine | Significato |
|---|---|
| Agent Runtime | Runtime che gestisce sessione, pianificazione, strumenti, risorse e ciclo operativo. |
| EventBus | Bus osservazionale per eventi e trace. |
| WorldState | Rappresentazione canonica dello stato corrente. |
| Perception | Sottosistema che osserva l'ambiente. |
| Simulation | Sottosistema che predice risultati senza eseguire. |
| Tactical Ranking | Valutazione e ordinamento dei candidati. |
| Orchestrator | Coordinatore dei sottosistemi. |
| Guard | Valutazione del contesto operativo e delle policy. |
| Trust | Livello deterministico di autorizzazione. |
| Safety Gate | Confine finale per le azioni protette. |
| Executor | Componente che esegue azioni autorizzate. |
| Verifier | Componente che verifica il risultato reale. |
| RecoveryController | Controller adattivo per retry, replan e modalità di recupero. |
| Watchdog | Controllore di salute e budget del runtime. |
| Cooling | Modalità di raffreddamento e riduzione del carico. |
| Context Slimming | Riduzione del contesto diagnostico per limitare memoria e VRAM. |
| Decision Provider | Componente che produce dati decisionali per il runtime. |
| Replay | Ricostruzione di un'esecuzione a partire da trace e stato. |
