# Runbook operativi

## Contenuto

La cartella `docs/runbooks/` contiene i runbook operativi per build, test, rilascio e ripristino di NosAi. Ogni runbook descrive una procedura ripetibile con precondizioni e verifica finale. La procedura di build, test e rilascio è già documentata in `docs/BUILD_TEST_RELEASE.md`.
