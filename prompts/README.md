# Prompt riutilizzabili

## Prompt disponibili
- **Prompts/local_documentation.md**: Genera documenti locali.
- **Prompts/module_contract.md**: Formula contratti di modulo.

## Regole di stesura
- Un prompt riutilizzabile deve includere i fatti verificati.
- Deve dichiarare il formato di uscita atteso e i divieti.
- Non deve contenere segnaposto non risolti.

## Dove vivono i prompt di sistema
I prompt di sistema dei tool MCP sono definiti all'interno di `scripts/mcp_server.py`, uno per ciascun tool.
